# สมุดคะแนนรายห้อง

เว็บบันทึกคะแนนรายห้อง: เพิ่มงาน กรอกคะแนน เช็คชื่อ ให้คะแนนเสริม และสรุปเกรด
หน้าเว็บโฮสต์ฟรีบน GitHub Pages ส่วนข้อมูลเก็บใน **Google Sheet ของคุณเอง**

- ใช้ได้ทันทีโดยไม่ต้องเชื่อมต่อ (ข้อมูลเก็บไว้ในเครื่องที่ใช้งาน)
- เมื่อเชื่อม Google Sheet ข้อมูลจะซิงก์ทุกเครื่อง และเปิดดูหรือพิมพ์จากชีตได้
- เว็บเร็ว เพราะแสดงข้อมูลจากเครื่องทันที แล้วค่อยบันทึกลงชีตเองเบื้องหลัง

## ติดตั้ง Google Sheet (ประมาณ 5 นาที ทำครั้งเดียว)

1. สร้าง Google Sheet ใหม่ที่ https://sheets.new ตั้งชื่อ เช่น `สมุดคะแนน`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs)
4. แก้บรรทัด `const PIN = 'เปลี่ยนรหัสนี้';` ให้เป็นรหัสของคุณ เช่น `'wc2569'` แล้วกด 💾 บันทึก
5. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้งานในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. กด **ทำให้ใช้งานได้** แล้วกด **ให้สิทธิ์เข้าถึง** ด้วยบัญชี Google ของคุณ
   (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจกต์ (ไม่ปลอดภัย) เพราะเป็นโค้ดของคุณเอง)
7. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
8. เปิดหน้าเว็บสมุดคะแนน กดปุ่มสถานะมุมขวาบน (หรือเมนู ⋯ → 🔗 เชื่อมต่อ Google Sheet)
   วาง URL และใส่ PIN แล้วกด **เชื่อมต่อ**

ถ้ามีข้อมูลในเครื่องอยู่ก่อนแล้ว ข้อมูลนั้นจะถูกส่งขึ้นชีตให้อัตโนมัติ
เครื่องอื่น ๆ (มือถือ แท็บเล็ต) ใส่ URL และ PIN เดียวกันครั้งเดียว ก็จะเห็นข้อมูลชุดเดียวกัน

## ในชีตจะเห็นอะไร

แต่ละห้องจะมี 3 แท็บที่สร้างใหม่อัตโนมัติทุกครั้งที่บันทึก

| แท็บ | เนื้อหา |
|---|---|
| `ม.4-1 คะแนน` | เลขที่ รหัส ชื่อ คะแนนทุกงาน คะแนนเสริม รวม ร้อยละ เกรด มาเรียน % |
| `ม.4-1 เช็คชื่อ` | ตาราง วันที่ × นักเรียน (มา/ขาด/ลา/สาย) พร้อมสรุป |
| `ม.4-1 คะแนนเสริม` | รายการคะแนนเสริมทุกครั้ง พร้อมวันที่ เหตุผล และยอดรวม |

ชีต `_data` ถูกซ่อนไว้และเก็บข้อมูลดิบ **ห้ามแก้ไข**
ให้แก้คะแนนผ่านหน้าเว็บเท่านั้น ถ้าแก้ตัวเลขในแท็บที่อ่านได้โดยตรง จะถูกเขียนทับในการบันทึกครั้งถัดไป

## อัปเดตโค้ด Apps Script ภายหลัง

ถ้ามีการแก้ไฟล์ `Code.gs`: วางโค้ดใหม่ → Deploy → **จัดการการทำให้ใช้งานได้ (Manage deployments)** → ✏️ แก้ไข → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้
(วิธีนี้ทำให้ URL เดิมใช้ต่อได้ ไม่ต้องตั้งค่าใหม่ทุกเครื่อง)

## ความปลอดภัย

- หน้าเว็บเป็นสาธารณะ แต่ไม่มีข้อมูลนักเรียนอยู่ในหน้าเว็บ ข้อมูลอยู่ใน Sheet ที่ต้องใช้ PIN จึงอ่านหรือเขียนได้
- ตั้ง PIN ให้เดายาก และอย่าแชร์ URL `/exec` คู่กับ PIN
- สำรองข้อมูลเป็นไฟล์ได้จากเมนู ⋯ → 💾 สำรองข้อมูลทั้งหมด

## ส่งออกเป็นไฟล์ Excel / Google Sheet

เมนู ⋯ → **ส่งออก Excel / Google Sheet (.xlsx)** จะได้ไฟล์ 4 แผ่นงาน คือ สรุปผล, คะแนน, เช็คชื่อ, คะแนนเสริม
จัดรูปแบบพร้อมพิมพ์ (A4 แนวนอน) และมีสูตรคำนวณรวม ร้อยละ เกรด และค่าเฉลี่ยในตัว
เปิดด้วย Excel ได้ทันที หรืออัปโหลดเข้า Google Drive แล้วเปิดด้วย Google Sheets ใช้ได้แม้ไม่ได้เชื่อมต่อ Google Sheet
